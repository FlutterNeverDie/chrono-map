# features/events — 사건 카드·대륙 뷰·상세 (F-05, F-06)

## 책임
- 대륙별 카드 뷰, 사건 카드, 사건 상세 화면 구성.
- "선택 연도에 보여줄 사건" 계산은 `lib/events.ts`의 순수 함수로 한다(컴포넌트 안에서 필터링 로직 작성 금지).

## 표시 규칙
- 대륙 순서 고정: 아시아 → 유럽 → 아프리카 → 북아메리카 → 남아메리카 → 오세아니아 (`data/continents.ts` 순서).
- 사건이 없는 대륙도 카드는 보여주고 "이 시기 등록된 사건이 없어요"를 표시한다(빈 대륙 = 콘텐츠 부족 신호).
- 연도는 `formatYear()`, 기간 사건은 `formatYearRange()`.
- 같은 대륙 안에서는 연도 가까운 순, 같으면 importance 높은 순.

## 모바일 규칙
- 모바일: 대륙 카드가 세로로 쌓인다(1열). `md:` 2열, `lg:` 3열.
- 카드 전체가 탭 영역. 카드 안 텍스트는 최소 14px.
- 상세는 모바일에서 전체 화면 페이지(`/event/[slug]`), 카드 탭 시 하단 시트 미리보기를 거쳐 이동.
