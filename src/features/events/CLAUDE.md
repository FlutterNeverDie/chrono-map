# features/events — 사건 목록 (F-05, F-06)

## 책임

- `EventPanel`: 지도 위에 떠 있는 사건 목록 틀. 모바일은 게이지 위 접이식 시트(펼치면 위 끝이 화면 40% 지점 — 지도가 위에 보이게, 키 작은 기기에서도 상단 바(`--top-h`) 아래. 머리줄 오른쪽 X로 닫기), `lg:` 이상은 오른쪽 패널(`w-[26rem]`, `xl:` 30rem).
- `EventList`: 선택 연도에 걸치는 사건을 **현재 시점 기준 중요한 순서**로 나열(`useRankedEvents`). 카드는 20개씩 그리고 "더 보기"로 늘린다(기간이 바뀌면 처음으로, 고른 사건은 항상 보이게).
- `OtherMaps`: 패널 위쪽 "이 시기의 다른 지도" 칩(선택 기간과 겹치는 전쟁·주제 지도 항목, 중요한 순 최대 4개, `data/mapMarkers.ts`의 `markersIn`). 누르면 그 지도로 이동(주제 지도는 `?item=<id>`로 그 항목을 고른 채 시작).

## 규칙

- 정렬·필터 로직은 `lib/events.ts`, `lib/ranking.ts`에만. 이 모듈은 결과를 그리기만 한다.
- 정렬 기준 시점은 `useRankingViewpoint()`(선택된 시점, 지도를 끌었으면 가운데와 가장 가까운 시점).
- 카드: 지역(색 점 + 이름) · 때(`formatWhen`) · 장소 · 진행 중 배지 / 제목(`eventTitle`) / 설명(`eventSummary`, 위키백과 첫 문단 그대로, 4줄로 접고 "자세히"를 누르면 그 자리에서 펼침 — 페이지 이동 없음) / 위키백과 링크 + "CC BY-SA 4.0" / 전쟁 지도 버튼(있으면). 본문 글자는 14px 미만으로 줄이지 않는다.
- 사건 상세 페이지(/event/[id])는 검색 노출용으로 남겨 두되 카드에서는 링크하지 않는다.
- 위키백과 원문을 보여줄 때는 **반드시** 문서 링크와 라이선스를 함께 표시한다(CC BY-SA 4.0 조건). 다른 언어 원문을 대신 보여줄 때는 `lang` 속성을 붙인다.
- 문구는 i18n 사전.
- 지도 핀을 탭하면 패널이 열리고 해당 카드로 스크롤·강조(`id="event-<사건id>"`). 카드를 탭해도 선택된다.
- 상세는 나중에 `/event/[slug]`(언어별) 페이지로 만든다.
