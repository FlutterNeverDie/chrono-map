# features/filters — 지역·카테고리 필터 (F-07)

## 책임

- 지역 토글, 카테고리 토글 UI. 상태는 `store/filters`에만 저장한다.

## 규칙

- 기본값: 전부 선택. 하나도 선택 안 된 상태가 되지 않게 마지막 하나는 해제 불가.
- 모바일: 상단에 가로 스크롤 칩(chip) 목록 또는 하단 시트. 칩 높이 최소 36px, 터치 영역 44px.
- 데스크톱: 헤더 옆 칩 목록.
- 필터 상태는 URL 쿼리(`?r=korea,europe`)와 동기화할 수 있게 직렬화 함수를 `lib/`에 둔다(F-12 공유 대비).
