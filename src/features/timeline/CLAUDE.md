# features/timeline — 연도 게이지 (F-01~03, F-10)

## 책임

- 연도 선택 UI(게이지), 시대 레이블 띠, 이전/다음 버튼, (나중에) 자동 재생.
- 선택은 연도 하나가 아니라 **기간**이다(기원전 세기 / 서기 `step`년 - 기본 10년, 설정의 `YearStepSetting`에서 5·10·30·50·100, `lib/period.ts`의 `YEAR_STEPS`). 단위는 `store/timeline`의 `step`, localStorage(`yearStep`, 기본값이면 지움)에 저장하고 `useSavedYearStep`이 하이드레이션 뒤 불러온다(주소의 `?y`보다 먼저 - YearGauge에서 useYearUrl보다 앞에 부름). `store/timeline`의 `year`는 기간 시작 연도로 맞춰 저장되고, 화면에서는 `usePeriod()`로 읽는다.
- 슬라이더는 비선형 축 위치를 연도로 바꾼 뒤 기간 시작으로 맞춘다. ◀ ▶는 한 기간씩 이동.
- 현재 기간 표시는 손잡이 바로 위 말풍선. 사건 패널 제목 옆에는 실제 연도 범위(`formatPeriodRange`: 1490–1499년)를 함께 보여준다.
- 첫 화면 연도는 1940년대(제2차 세계대전, `store/timeline`). 주소의 `?y=연도`와 선택 기간을 맞춘다(`useYearUrl`, 공유 링크 F-12). 주소 갱신은 연도가 0.4초 멈춘 뒤에만(History API 호출 제한, Safari 30초 100번). 개발 모드에서 효과가 두 번 실행돼도 처음 주소 값을 잃지 않도록 ref로 들고 있는다.
- `MapLanes`: 슬라이더 위에 쌓는 얇은 띠(전쟁 지도 1줄 + 주제 지도마다 1줄, `data/mapMarkers.ts`). "이 시기쯤 이런 지도가 있다"는 안내이며, 선택 기간과 겹치는 표식은 진하게, 누르면 그 지도로 이동. 띠는 손잡이 드래그를 막지 않도록 표식 외에는 `pointer-events-none`이고, 슬라이더(터치 영역 h-12)보다 위 층(`z-10`)이어야 표식이 눌린다. 주제 지도가 늘면 띠도 자동으로 늘어난다.

## 시간 축

- 게이지 내부 값은 0~1000 정수 위치값이고, 연도 변환은 `lib/timeScale.ts`(`positionToYear`/`yearToPosition`)만 사용한다.
- 비선형 축: 고대는 넓은 간격, 근현대는 좁은 간격. 구간 정의는 `lib/timeScale.ts` 한 곳에서만 바꾼다.
- 범위: 기원전 3000년 ~ 현재 연도.

## 모바일 규칙

- 하단 바 안에서 남는 가로폭을 모두 쓴다(최대 폭 제한 없음).
- 손잡이는 보이는 점 16px, 터치 영역 44px. 이전/다음은 화살표 아이콘 버튼.
- 시대 레이블은 게이지 아래에 두고, 탭하면 그 시대 시작 연도로 이동한다. 좁은 화면(< sm)은 현재 시대 이름만 보이고 나머지는 눈금만(언어에 따라 글자가 길어 겹침).
- 게이지는 `dir="ltr"` 고정 — 아랍어(RTL)에서도 시간은 왼쪽(과거) → 오른쪽(현재).
- 문구(aria, 시대 이름)는 i18n 사전에서 가져온다.
- 드래그 중에는 연도 숫자만 즉시 갱신하고, 무거운 갱신(지도 핀 등)은 소비하는 쪽에서 처리한다.
- 정밀 이동용 ◀ ▶ 버튼을 반드시 둔다(손가락 드래그로는 1년 단위 조작이 어렵다).

## 접근성

- `@radix-ui/react-slider` 사용(키보드 ←→, aria 기본 제공). `aria-valuetext`에는 `formatYear()` 결과를 넣는다.
