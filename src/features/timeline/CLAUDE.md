# features/timeline — 연도 게이지 (F-01~03, F-10)

## 책임

- 연도 선택 UI(게이지), 시대 레이블 띠, 이전/다음 버튼, (나중에) 자동 재생.
- 선택 연도는 `store/timeline`에만 저장한다. 이 모듈 안에 연도 상태를 따로 두지 않는다.

## 시간 축

- 게이지 내부 값은 0~1000 정수 위치값이고, 연도 변환은 `lib/timeScale.ts`(`positionToYear`/`yearToPosition`)만 사용한다.
- 비선형 축: 고대는 넓은 간격, 근현대는 좁은 간격. 구간 정의는 `lib/timeScale.ts` 한 곳에서만 바꾼다.
- 범위: 기원전 3000년 ~ 현재 연도.

## 모바일 규칙

- 하단 바 안에서 남는 가로폭을 모두 쓴다(최대 폭 제한 없음).
- 손잡이는 보이는 점 16px, 터치 영역 44px. 이전/다음은 화살표 아이콘 버튼.
- 시대 레이블은 게이지 아래에 두고, 탭하면 그 시대 시작 연도로 이동한다. 좁은 화면(< sm)은 현재 시대 이름만 보이고 나머지는 눈금만(언어에 따라 글자가 길어 겹침).
- 게이지는 `dir="ltr"` 고정 — 아랍어(RTL)에서도 시간은 왼쪽(과거) → 오른쪽(현재).
- 문구(aria, 시대 이름)는 i18n 사전에서 가져온다.
- 드래그 중에는 연도 숫자만 즉시 갱신하고, 무거운 갱신(지도 핀 등)은 소비하는 쪽에서 처리한다.
- 정밀 이동용 ◀ ▶ 버튼을 반드시 둔다(손가락 드래그로는 1년 단위 조작이 어렵다).

## 접근성

- `@radix-ui/react-slider` 사용(키보드 ←→, aria 기본 제공). `aria-valuetext`에는 `formatYear()` 결과를 넣는다.
