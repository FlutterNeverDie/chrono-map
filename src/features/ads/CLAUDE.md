# features/ads — AdSense (F-08)

**보류: 개발 완료 후 배포 단계에서 작업한다. 지금은 코드 작성 금지.**

## 나중에 지킬 규칙
- 광고 스크립트는 `next/script`로 한 번만 로드. 슬롯은 `<AdSlot>` 클라이언트 컴포넌트.
- 광고가 게이지·카드 탭 영역을 가리거나 밀어내지 않는다. 슬롯 크기를 미리 확보해 레이아웃 이동(CLS) 방지.
- 모바일: 카드 5~6개마다 인피드 1개, 하단 앵커 광고는 게이지와 겹치지 않게 배치.
- 데스크톱: 우측 사이드바 300x600.
- 개발 환경(`NODE_ENV !== "production"`)에서는 회색 자리표시자만 렌더.
