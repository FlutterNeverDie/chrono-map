# features/ads — AdSense (F-08)

기반 코드만 있다. **게시자 ID·광고 단위 ID(환경변수)를 넣기 전까지 아무것도 그리지 않는다** — 화면·성능은 광고가 없을 때와 같다.
실제 연결(계정·승인·광고 단위 만들기)은 `docs/launch.md` 순서대로 사용자와 함께 진행한다.

| 파일                          | 역할                                                                                                       |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `config.ts`                   | 환경변수 `NEXT_PUBLIC_ADSENSE_CLIENT`(ca-pub-…), `NEXT_PUBLIC_ADSENSE_SLOT_ARTICLE` → 설정, `adsTxtLine()` |
| `AdsScript.tsx`               | AdSense 스크립트(RootDocument에서 한 번). 운영 빌드 + 게시자 ID가 있을 때만                                |
| `AdSlot.tsx`                  | 광고 한 칸(반응형). 개발 모드는 회색 자리표시자, 자리 높이 280px를 미리 잡아 CLS 방지                      |
| `app/(home)/ads.txt/route.ts` | `/ads.txt` (게시자 ID가 있을 때 채워짐). 빌드 후 정리(prune-out)가 지우지 않게 예외 처리됨                 |

## 배치 규칙

- 광고 자리(모바일·데스크톱 같음):
  - 글 페이지: 사건 상세 본문 아래, 연도 페이지 사건 목록 아래(`article`).
  - 지도 화면: 사건·전투·항목 목록의 **3번째 카드 뒤 한 칸**(`infeed`) — 모바일은 목록을 펼쳤을 때만 보인다.
  - features끼리 import하지 않으므로 목록·페이지 컴포넌트가 `ad` prop을 열어 두고 app 화면이 `<AdSlot>`을 넣는다(목록 사이 끼우기는 `components/ui/withAd`).
- 지도 위·슬라이더 주변·하단 고정(앵커) 광고·전면(비네트) 광고는 넣지 않는다 — 지도와 게이지를 가린다. 자동 광고를 켜면 이 둘을 끄고 글 페이지에만.
- 배치 확인: `NEXT_PUBLIC_ADS_PREVIEW=1 npx next dev` → 광고 자리가 회색으로 보인다.
- 개발 모드에서 실제 광고를 요청하지 않는다(무효 트래픽). 자동 광고(Auto ads)는 승인 후 글 페이지에서만 시험.
- 동의 메시지(CMP, EEA·영국·스위스)는 AdSense 화면의 "개인 정보 보호 및 메시지"에서 켠다(코드 없음). 개인정보처리방침에 관련 문구·링크가 있다.
- 광고를 못 채우면 애드센스가 `<ins data-ad-status="unfilled">`를 붙인다 → `AdSlot`이 Tailwind has 변형으로 "광고" 표시까지 통째로 숨긴다(빈 회색 칸이 남지 않게).
