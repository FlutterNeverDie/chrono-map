# 지도 위 나라 이름 - 원본이 엉뚱한 위키 문서에 이어진 정치체의 문서 바꾸기 (8개 언어 공통)
# 형식: 원본 이름(public/borders/*.json의 "n" 값 그대로) = 영어 위키백과 문서 제목
# 원본(Cliopatria)의 Wikipedia 칸이 사건·인물·역사 문서를 가리켜 모든 언어에서 이름이 틀리던 것
# (예: Qarlugs → "Mongol invasion of Central Asia", Kingdom of Numidia → "Jugurtha").
# 여기 적은 문서의 Wikidata 항목에서 8개 언어 이름을 다시 받는다. "X"에 적으면 "(X)"에도 적용된다.
# 언어별 파일(<언어>.txt)에 적은 이름이 이것보다 우선한다. 적용: npm run borders (새 문서는 위키백과·Wikidata에서 받음)
# 알맞은 문서가 없는 것은 언어별 파일에 직접 적는다.
# 연도에 따라 나라가 바뀌는 것(Great Britain → United Kingdom 1801~, Mali Federation → Mali 1961~)과
# 도형 오류(1962년 이후 프랑스에 붙은 알제리 등)는 scripts/lib/polityFixes.mjs의 POLITY_FIXES에서 고친다(본 지도·전쟁 지도 공통).
